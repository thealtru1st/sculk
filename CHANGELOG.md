# Changelog

## 0.1.0 — unreleased

First public release.

- Minecraft Java Edition 26.1.2 (protocol 775) offline-mode server.
- Seeded procedural world: biomes, trees, caves, ores, water.
- Block breaking with vanilla loot and tool rules, block placement, 46-slot inventories, 2×2 and 3×3 crafting with the vanilla crafting recipes.
- Multiplayer movement, chat, tab list, sneaking and arm swing.
- `--world` saves for block edits and inventories; `--seed` and `--motd` options.
- `sculk-bench` synthetic clients, managed benchmarks, gameplay self-check, memory-limit sweeps.
